# v0.1.0 — Read-only PID50 monitoring

Initial public release of the Pentek IntelliDrive PID50 integration for Home
Assistant. See the integration manifest for the minimum supported Home Assistant version.

## Included

- HACS custom-repository installation and UI configuration.
- 49 holding-register sensors plus Running, Sleeping, and Fault active binary
  sensors: 17 entities enabled by default and 35 optional diagnostics.
- Local Modbus TCP reads through a TCP-to-RS-485 gateway, with serialized,
  bounded requests and strict response validation.
- Live pressure, setpoint, frequency, electrical telemetry, operating state,
  run mode, and fault code, plus diagnostic configuration readings.
- Named enum states with numeric `raw_value` attributes. Active-fault detection
  uses operating state rather than a potentially latched historical fault code.
- A generic dashboard example and manual migration guide covering entity
  remapping, helper preservation, and raw-history limitations.

## Verified scope

Automated protocol, package, migration, and Home Assistant lifecycle tests cover
the runtime implementation. See the repository's Actions checks for the tagged
release revision and `AUDIT.md` for the detailed validation boundaries.

## Important limits and migration notes

- Monitoring only: no controller writes, pump controls, or configuration changes.
- Disable the old PID50 Modbus poller before enabling this integration. Migration
  is manual; raw entity history and statistics are not automatically transferred.
- Not every register has been independently checked against the controller
  display, and not every operating mode has been physically observed.
- Real fault/recovery events, over-pressure, dry-run, extended soak testing, and
  actual gateway-loss recovery remain unvalidated. No faults were intentionally
  induced for testing.
- Other drive models, firmware revisions, and gateways are unverified.
- Community software, not a safety controller; retain the drive's independent
  protections. HACS default-catalog inclusion is not part of this release.
