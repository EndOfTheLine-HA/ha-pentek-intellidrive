# v0.1.1: No stale readings, bounded reads

Robustness update for the read-only PID50 integration. Still read-only: every
request is a Modbus function code 3 read, now enforced by a test across all
register blocks.

## Changes

- A value whose registers were read but could not be decoded (for example a
  non-finite frequency or power reading) is no longer left at its previous
  value. Its sensor goes unavailable until a valid reading arrives, so a stale
  "running" or pressure value is never shown as current.
- Each Modbus transaction now has one overall deadline, so a gateway that sends
  its reply a byte at a time can no longer hold a read open for hours.
- A reply that announces an impossible length is rejected before its body is
  read.

## Upgrade notes

Update through HACS and restart Home Assistant. No configuration changes are
needed. Sensors may briefly show unavailable if the drive reports an invalid
value, which previously would have been hidden behind the last good reading.
